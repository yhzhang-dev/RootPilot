# RootPilot 演示视频大纲

> 目标：面向课程答辩 / 教师评审的 3–5 分钟演示。重点是「本地优先的 Android Root 控制台」如何把课程要求的平台组件（文件 / Preferences / SQLite / Provider / Service / Broadcast / 网络）串成一个真实工具，并展示安全边界与桌面 Agent 能力。

## 一、视频信息

| 项 | 内容 |
|---|---|
| 时长 | 3–5 分钟（建议 4 分 30 秒） |
| 设备 | OnePlus PHK110（Android 16，KernelSU 已授权 Root） |
| 录制 | 手机录屏 + 桌面终端录屏（可画中画或分段拼接） |
| 旁白 | 中文 |
| 重点 | 功能闭环 + 课程组件映射 + 安全边界 + 桌面 Agent |

## 二、开录前准备

- 构建并安装最新 APK：`gradlew.bat :app:assembleDebug` → `adb install -r app\build\outputs\apk\debug\app-debug.apk`；
- 准备一个**可冻结的测试应用**（例如 `com.hangge.myapplication`），不要选系统、桌面或输入法；
- 手机开深色主题、清空通知栏、关闭无关弹窗；
- 桌面终端字号放大、清屏；确认 `adb devices` 能看到设备；
- Agent 演示前：应用内启动服务、复制 Token，桌面执行 `scripts\connect-agent.ps1`；
- 录屏期间**不要显示 Token 明文**，用 `***` 代替。

## 四、旁白脚本要点（每段 1–2 句）

1. **定位**：RootPilot 不是玩具，它把课程要求的文件、Preferences、SQLite、Provider、Service、广播和网络，做成一个能日常使用的 Root 巡检工具。
2. **总览**：设备信息、Root 状态、电池和存储一屏可见，快照落库便于回看。
3. **应用**：全量应用列表、即时搜索与筛选；详情展示权限，写操作前有保护。
4. **安全**：SafeMode 拦住冻结与强制停止，但解冻永远可用；被拒绝的尝试也会记录。
5. **审计**：Room 记录每次快照、操作和 API 请求，可导出 JSON/CSV，令牌永不导出。
6. **Agent**：前台服务 + 回环 HTTP + Token；桌面通过 ADB 转发访问，写操作还要显式开关。
7. **桌面**：类型化的截图、UI 树和观察—动作—观察闭环，配合 MCP，桌面 Agent 可以安全操作。

## 五、录屏清单（开录前逐项勾选）

- [ ] APK 已安装并能冷启动到总览页；
- [ ] `adb devices` 显示设备已授权；
- [ ] 测试应用可冻结 / 解冻；
- [ ] SafeMode / Allow Agent Control 状态符合流程；
- [ ] Agent 服务已启动，Token 已复制；
- [ ] `adb forward tcp:8765 tcp:8765` 已建立且 `/v1/health` 可访问；
- [ ] 手机深色主题、通知栏无干扰；
- [ ] 桌面终端字号放大、清屏。

## 六、注意事项

- 不要把 Token 明文放进画面；需要展示时用 `***`。
- 冻结只选测试应用，避免冻结系统、桌面、输入法。
- 时长控制在 5 分钟内；素材不够时，优先保留「应用操作 + Agent + 安全边界」。
- 可用手机自带录屏 + 桌面 OBS，后期配音；关键步骤可加 1 秒定格与字幕。
