## 2026-11-13（夜）

### 无障碍桥与多开支持

驱动原因：桌面 Agent 在微信上连"点发送"都点不动，排查下来分别踩到三个坑——组合观察 16–25 秒
且丢 UI、输入法窗口吞点击、`input text` 被拼音输入法吃掉。

1. **新增 `RootPilotAccessibilityService`**：导出与 uiautomator 兼容的节点树（附 `node-index`）、
   节点点击（`ACTION_CLICK` → 祖先 → 手势）、文本写入（`ACTION_SET_TEXT`）。
2. **采集降级链路**：`/v1/ui/tree` 与观察优先无障碍、回退 uiautomator，响应标 `source`。
   组合观察从 16–25 秒降到 0.9–2.2 秒，且不再丢 UI 半。
3. **`/v1/ui/windows`**：窗口类型/包名/bounds/焦点，观察结果附 `occluders`，点击前先判断是否被键盘遮挡。
4. **分身支持**：`foregroundUserId`、窗口 `userId`、`launch?user=N`。`context.startActivity` 永远
   落在 user 0，启动分身改用 `resolve-activity` + `am start --user`。
5. **文本与手势**：`clipboard` / `paste`（Ctrl+V）、`tap` 的 `holdMs`（分离 DOWN/UP）。

### 关键决策（新增）

- D16 无障碍优先、uiautomator 兜底；D17 窗口几何单独成接口；D18 分身靠 userId；
  D19 文本输入三档降级；D20 长按用分离事件。

### 验证

- 无障碍树 0.5s（111 节点）对比 uiautomator 2.9s；组合观察 0.9–2.2s。
- 节点点击、`ACTION_SET_TEXT`（中文）、剪贴板粘贴（3 行中文并发送）、长按开朋友圈「发表文字」均通过。
- 主号 / 分身切换：`userId` 0 ↔ 999 正确，窗口归属同步。
- `assembleDebug`、`testDebugUnitTest` 通过。

## 2026-11-13（日）

### 里程碑（按构建顺序）

1. **脚手架**：Gradle + AGP + Kotlin + Compose Material 3，单 `MainActivity` + 四个底部标签 + 顶栏设置。
2. **数据层**：Room（快照/操作/API 请求三张表，`exportSchema=true`）、SharedPreferences 设置、Keystore 加密 Token、仓储。
3. **Root 与设备**：`RootShell` 固定枚举命令、超时与输出上限；无 Root 时降级为只读巡检。
4. **应用**：`PackageManager` 全量列表（494 个）、搜索/筛选、详情与权限。
5. **操作与历史**：`ActionExecutor` 唯一执行入口，冻结/解冻/强制停止，SafeMode 拦截，占位记录改写。
6. **Provider 与导出**：只读 ContentProvider + 应用内自检，JSON/CSV 经 SAF 导出并写内部副本。
7. **服务与 API**：前台 `AgentService` + `AgentServer`（回环、Token、请求审计、应用内自检）。
8. **广播**：动态电池广播、静态开机广播（15 分钟 OEM 重放过滤）。
9. **Agent v2**：通知监听、长轮询事件、定位/传感器订阅、截图与 UI 树、观察—动作—观察闭环、零依赖 MCP Server、课程主线一键链路演示。

### 关键决策

- 写接口统一要求 `AllowAgentControl`；`SafeMode` 只拦截冻结/强制停止，解冻始终可用（D1）。
- 鉴权失败补 `UNAUTHORIZED` 错误码；其余错误码严格遵循简报（D2）。
- 操作审计先插占位记录、执行后原行改写，避免重复行（D3）。
- 手动 `AppContainer`，不引入 Hilt（D6）；图标手绘，避免额外依赖（D7）。
- 实时事件用长轮询而非 WebSocket（D13）；自动化采用观察—动作—观察（D14）；MCP 是桌面适配层（D15）。

### 验证

- PHK110（Android 16 / KernelSU）手工验收通过：总览、快照、应用搜索、冻结/解冻、SafeMode 拦截、前台服务、`/v1/health` 200、无 Token 401、Provider 自检、JSON 导出、通知监听、定位/传感器、截图/UI 树、MCP 初始化。
